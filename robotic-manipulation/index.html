第二周配套 MATLAB 示例

开始之前

程序面向 MATLAB R2025a。示例 01–15、18 仅需基础 MATLAB；示例 16–17 使用 UR5e 模型，需要 Robotics System Toolbox。

  1. 下载并解压 MATLAB 程序包。
  2. 将 MATLAB 的 Current Folder 切换到 robotics_week2_matlab 文件夹。
  3. 运行环境检查，再选择单个示例或依次运行全部示例。
setup_check
% 示例：相机、世界与基座之间的坐标转换
demo09_coordinate_chain_camera_base
% 或依次运行全部课堂示例
run_all_demos

程序包内的 README.md 提供环境与记号说明，LECTURE_MAP.md 列出课件页码和脚本的对应关系。角度使用弧度，长度默认使用米。
