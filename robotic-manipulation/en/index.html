Before You Begin

The examples target MATLAB R2025a. Examples 01–15 and 18 use base MATLAB. Examples 16–17 use the UR5e model and require Robotics System Toolbox.

  1. Download and extract the MATLAB code archive.
  2. Set MATLAB’s Current Folder to robotics_week2_matlab.
  3. Run the environment check, then run one example or the full sequence.
setup_check
% Example: camera, world, and base frame transformations
demo09_coordinate_chain_camera_base
% Or run all examples in sequence
run_all_demos

The archive includes README.md for setup and notation, and LECTURE_MAP.md for the mapping between slide pages and scripts. Angles are in radians and lengths are in meters by default.
